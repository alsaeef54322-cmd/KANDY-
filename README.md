# نظام كاندي لإدارة المحمصة والمبيعات والمخزون والحسابات
## KANDY Roastery & Confectionery Management System

تم تصميم وتطوير هذا النظام خصيصاً لإدارة محمصة ومحل مكسرات وشوكولاتة وحلويات للأستاذ **إبراهيم راغب**.

---

### 1. مميزات النظام الرئيسية

- **واجهة Desktop-first احترافية بالكامل باللغة العربية مع دعم RTL أصيل** ومتناسق مع الهوية البصرية لمحمصة كاندي (ألوان الشوكولاتة الداكنة، البيج الدافئ، والتنظيم المريح).
- **حساب المدير العام الوحيد**: الأستاذ إبراهيم راغب يتمتع بصلاحيات كاملة لإدارة المبيعات، المخزون، الشراء، المصروفات، الخزنة، والأرباح.
- **نقطة بيع POS سريعة للمحمصة**:
  - تدعم المنتجات الموزونة (بالجرام والكيلو) والمعبأة وبالقطعة.
  - أزرار سريعة للأوزان: ربع كيلو (250 جرام)، نصف كيلو (500 جرام)، 750 جرام، كيلو كامل، ووزن حر مخصص.
  - قارئ باركود سريع ودعم ماسح الكاميرا.
  - طباعة إيصالات حرارية قياس 80 مم وفواتير ضريبية.
  - تعليق الفواتير واسترجاعها، والبيع النقدي والآجل وبالبطاقة.
- **دقة الحسابات المحاسبية والمخزنية**:
  - تتبع التكلفة بطريقة **متوسط التكلفة المرجح المتحرك (Moving Weighted Average Cost)** عند كل استلام مشتريات.
  - حساب تكلفة البضاعة المباعة (COGS) بدقة الجرام لكل صنف مباع.
  - صافي الربح = مجمل الربح - المصروفات التشغيلية - تكلفة التالف والهالك.
  - ربط كامل بين الخزنة والمبيعات النقدية والمصروفات ودفعات الموردين دون ازدواجية.
- **تصدير حقيقي إلى ملفات Excel و Word**:
  - تصدير ملفات `.xlsx` حقيقية منسقة بالأعمدة العربية والإجماليات.
  - تصدير مستندات Word بصيغة `.doc` متوافقة مع ترويسة كاندي الرسمية.
- **النسخ الاحتياطي الكامل**: تصدير واسترجاع ملفات JSON لقاعدة البيانات والتحقق من سلامتها.

### 2. الأقسام الـ 21 في القائمة الجانبية

1. **الرئيسية**: لوحة تحكم ذكية بـ 5 بطاقات أداء رئيسية، ورسم بياني لحركة المبيعات، وتوزيع الأصناف الأكثر مبيعاً، وتنبيهات النواقص.
2. **نقطة البيع والمبيعات**: شاشة كاشير سريعة مع السلة وحساب البواقي والطباعة.
3. **الفواتير والمرتجعات**: استعراض الفواتير السابقة، إعادة الطباعة، وتسجيل المرتجعات مع إعادة المخزون.
4. **المنتجات والأقسام**: بطاقات الأقسام، كتالوج المنتجات، تعديل أسعار الشراء والبيع وحدود التنبيه.
5. **المخزون وحركة الأصناف**: سجل حركات الإضافة والخصم بالألوان (+5.000 كجم بالأخضر، -0.250 كجم بالأحمر).
6. **المشتريات**: فواتير التوريد متعددة الأصناف، تحديث التكلفة، وإدارة ديون الموردين.
7. **الموردون**: دليل الموردين، المستحقات، وسداد الدفعات النقدية.
8. **حسابات الموردين**: كشف حساب تفصيلي لكل مورد بالفواتير والدفعات.
9. **العملاء**: دليل العملاء والديون الآجلة.
10. **حسابات العملاء والديون**: كشف حساب العميل والتحصيل النقدي وتوريده للخزنة.
11. **المصروفات**: تصنيفات الإيجار، الرواتب، الكهرباء، والتعبئة، مع التمييز بين المصروف المستحق والمدفوع.
12. **الموظفون والرواتب والسلف**: إدارة كادر العمل، صرف السلف النقدية، وإصدار مسيرات الرواتب.
13. **الخزنة والحسابات المالية**: رصيد الصندوق اللحظي، قيود الإيداع والسحب والتسوية، ويومية النقدية.
14. **الأرباح والخسائر**: بيان الدخل التفصيلي (صافي المبيعات، COGS، مجمل الربح، المصروفات، صافي الربح)، وهامش الربح.
15. **التقارير والتصدير**: 10 نماذج تقارير تفصيلية جاهزة للتصدير الفوري إلى Excel و Word والطباعة.
16. **التالف والهالك**: تسجيل عينات التذوق وتلف التحميص وخصمها من المخزون مع قيد خسارة التكلفة.
17. **الجرد والتسويات**: مقارنة العد الفعلي بالمخزون الدفتري واعتماد التسويات تلقائياً.
18. **المستخدمون والصلاحيات**: ملف المدير العام الأستاذ إبراهيم راغب، مصفوفة الصلاحيات، وتغيير كلمة المرور.
19. **سجل النشاط والتدقيق**: سجل زمني غير قابل للتعديل يوثق كافة العمليات.
20. **النسخ الاحتياطي**: حفظ واسترجاع وتنزيل نسخة كاملة من النظام.
21. **الإعدادات**: بيانات المحمصة، العنوان، الهاتف، نصوص الإيصالات، وخيارات الطباعة.

### 3. طريقة التشغيل

```bash

npm install

# تشغيل خادم التطوير
npm run dev

# فحص واختبار الأخطاء
npm run lint

# بناء نسخة الإنتاج
npm run build
```
